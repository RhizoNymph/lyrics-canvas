I want to have an infinite canvas where I can make a new rectangle to type lyrics into and when typing it aligns the syllables vertically across lines. I should be able to put in a "rest" to skip a syllable. It should show me how many syllables are in each line. I want to be able to add tags to each rectangle that holds a snippet and filter what shows on the canvas by tag. I want to be able to arrange them on the canvas and create groups that move together when I move the group but still allow me to move them around inside the group. I want a mode where I can perform t-sne embedding to 2 dimensions on the sentence embeddings and position them relative to each other based on the reduced dimensions. Maybe color the rectangles based on a third dimension but idk about that part. I also want to be able to use cosine similarity of tf-idf vectorized representations to see what is most similar to a particular snippet. I also want to have a sidebar where I can select a word or phrase and it will show me things that have rhymes or near rhymes to it.
